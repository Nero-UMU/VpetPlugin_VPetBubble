# VpetPlugin_VPetBubble

VPet 桌宠冒泡与戳泡泡小游戏插件。

这个插件会让桌宠在日常使用中生成各种泡泡，并提供一个可以计时计分的戳泡泡挑战模式。泡泡会从桌宠附近产生，向屏幕边缘飘动，鼠标碰到泡泡时会触发破裂动画并消失。

## 主要功能

- 日常模式自动生成普通泡泡
- 泡泡大小、颜色、透明度、高光和速度随机变化
- 鼠标触碰泡泡后自动移除，并播放破裂动画
- 支持多种日常泡泡生成模式
- 支持独立的戳泡泡挑战小游戏
- 支持保存设置和恢复默认设置

## 日常泡泡模式

### 普通泡泡

普通泡泡会从桌宠窗口中心生成，随机选择方向和速度漂向屏幕边缘。可以在设置中调整生成间隔、大小范围和速度范围。

### 泡之财宝

泡之财宝会在桌宠周围一圈的 16 个方向依次生成泡泡。生成顺序会随机选择顺时针或逆时针，泡泡会沿各自方向向外飞出。

### 光泡

光泡会随机选择上、下、左、右其中一个方向，在对应方向附近生成 5 个泡泡，并让这些泡泡统一朝同一个方向飞出。

### 泡泡炮

泡泡炮会让桌宠朝用户鼠标方向发射泡泡，只在日常模式中生效。

泡泡炮支持两种档位：

- 自动挡：持续不断地朝鼠标方向发射泡泡
- 半自动挡：按设定间隔触发一次连发，每次发射指定数量的泡泡

泡泡炮拥有独立外观设置，可以设置固定大小、速度，以及 16 种可随机选择的泡泡颜色。

## 戳泡泡挑战

戳泡泡挑战是一个独立小游戏模式。进入挑战模式后，会打开计分板窗口，可以设置游戏时间、泡泡参数和特殊生成概率。

挑战模式支持：

- 开始、暂停、继续、停止游戏
- 重置本局挑战
- 倒计时显示
- 点击泡泡计分
- 游戏结束结算界面
- 挑战模式独立参数设置
