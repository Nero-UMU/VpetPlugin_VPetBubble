# VPetBubble 插件

VPet 桌宠戳泡泡插件，桌宠现在会吹泡泡了，支持多种吹泡泡模式，触碰泡泡戳破它们吧

## 主要功能

- 日常模式生成普通泡泡
- 鼠标触碰泡泡戳破泡泡
- 多种泡泡生成模式
- 独立的戳泡泡挑战小游戏

## 日常泡泡模式

### 普通泡泡

桌宠会随机吹出泡泡并漂向屏幕外，在它逃走前戳破它吧，可在设置中调整泡泡参数

### 泡之财宝

泡之财宝会在桌宠周围一圈生成泡泡

### 光泡

桌宠会随机朝一个方向发射光泡

### 泡泡炮

泡泡炮会让桌宠朝用户鼠标方向发射泡泡，只在日常模式中生效

泡泡炮支持两种档位：

- 自动挡：持续不断地朝鼠标方向发射泡泡
- 半自动挡：按设定间隔触发一次连发，每次发射指定数量的泡泡

## 戳泡泡挑战

独立小游戏，可自定义挑战参数
